# Interactive Portfolio Website

A responsive personal portfolio website developed as part of the **Auspify Technologies Frontend Developer Internship**.

The website showcases my background, technical skills, projects, certificates and social profiles, with a contact form that allows visitors to reach me.

## 🌐 Live Demo

**Live Website:** https://vectacode.github.io/Internship-task-2-interactive-portfolio-website/

**GitHub Repository:** https://github.com/vectacode/Internship-task-2-interactive-portfolio-website

## ✨ Features

- Responsive layout for desktop, tablet and mobile screens
- Home and About sections
- Technical Skills section
- Projects showcase
- Certificates section
- Social media profile links
- Contact form integrated with Formspree
- Smooth navigation and interactive hover effects
- Scroll animations and back-to-top button
- Footer with automatically updated copyright year

## 🛠️ Technologies Used

- **HTML5** — website structure and content
- **CSS3** — styling, Flexbox, Grid, animations and responsive design
- **JavaScript** — interactive features and user experience enhancements
- **Git and GitHub** — version control and source code hosting
- **GitHub Pages** — website deployment
- **Formspree** — contact form submission handling

## 🚀 How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/vectacode/Internship-task-2-interactive-portfolio-website.git
   ```

2. Open the downloaded project folder in Visual Studio Code.

3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

No build process is required for this HTML, CSS and JavaScript project.
